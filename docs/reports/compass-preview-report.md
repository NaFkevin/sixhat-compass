# SixHat Compass · 六帽规划 Preview.3 验证报告

2026-10-24（Asia/Shanghai）。版本0.1.0-preview.3，包名dsh-sixhat-compass。此文记录本地验证范围；远程CI和Release状态以GitHub对应提交与发布页面为准。

## 实现与兼容

产品采用SixHat Compass · 六帽规划品牌。配置ID、内部hexamind命令、/api/hexamind路径与storages/hexamind目录有意保留，兼容旧设置、会话与评审；旧包和升级前测试备份保留，不重写冻结评测或旧历史。

原生单帽通常1次调用，不自动生成卡片或启动其他角色，模型tools=[]。nativeStart在检查点及宿主命令日志保存后确认受理，输入框由宿主清空；受理前失败保留草稿，受理后失败/停止在消息与记录页恢复。旧native完整结算API保持兼容。

机器摘要与公开测试截图位于compass-preview目录。调用次数、用量、来源条数、观察时间及回复哈希以实际机器记录为准；不分发完整运行库、凭据和私人会话。

## 复现与边界

使用安装说明配置隔离DSH、宿主全局默认模型和新版插件；发送公开计划与@黑帽，再用@绿帽继续。检查清空、草稿保留、职责、上下文和调用数；设置中修改回复长度，重启核对，再从记录页打开旧评审。

源码执行npm ci --ignore-scripts --no-audit --no-fund、npm run typecheck、npm run build、npm test；核对发行包SHA256。

已有非结构化开发者试用反馈，但正式真人产品价值验证及真人对照仍未完成。GitHub跨平台构建测试不等于其他平台DSH实测。本轮没有重做完整六帽真实调用、掉电、崩溃注入或卸载全链路，不把历史证据冒充本轮实测。全部中文输入法、真实附件、原生Desktop、其他供应商与未来宿主版本仍未完成验证。

宿主纯命令会话可能被视为空白或隐藏，使用@新讨论及记录页继续作为替代。崩溃恢复只到最后成功落盘检查点，取消后费用不可观测，来源关联不等于事实核验。
