# Skill 与旧插件能力差异

| 能力 | 纯 Skill | 旧 DSH 插件 Preview.5 |
|---|---|---|
| 六帽职责、自然语言建议、连续追问 | 保留，使用宿主当前模型与可见上下文 | 插件控制器调用宿主全局模型 |
| 默认路径 | 单帽；未指定帽子时蓝帽 | `@` 单帽或高级命令 |
| 综合评审、六帽评审、决策卡 | 用户主动要求后执行 | API 与控制器固定流程 |
| 六帽执行 | 同一模型组织六视角，不承诺次数 | 完整评审通常6次调用 |
| `@` 候选、设置页 | 不提供；使用宿主 Skill 入口 | 插件注册输入与设置扩展 |
| 历史、恢复、停止 | 宿主会话负责，不承诺独立检查点 | 插件记录与检查点 |
| 上下文 | 当前实际可见相关内容 | 固定最近20条、24000字符选择 |
| 调用与费用统计 | 不提供、不编造 | 插件真实调用记录 |
| 导出 | 回复可复制 Markdown，不自动写文件 | 编辑与导出界面 |
| 运行时依赖 | 无服务、无脚本、无专用密钥 | DSH 与兼容 SDK |
| 安装 | 复制完整 Skill 目录到宿主技能位置 | DSH 添加插件，安装 tgz |
| 用户决定与外部核验 | 用户决定留空；没有核验就明确未核验 | 同样保留证据与决定边界 |

“调用原理一样”仅指选择思考程序、分析相关材料、在当前聊天回答。Skill 没有独立模型调度器，也不提供强制权限隔离；指令边界的执行仍受宿主和模型行为影响。
