# Skill 0.1.0-preview.1

SixHat Compass · 六帽规划首次提供独立纯 Skill。标签 `skill-v0.1.0-preview.1`；旧插件的 `v0.1.0-preview.5` 等标签与安装包保持原样。

- 单帽、任务内追问、明确换帽、普通新问题退出角色。
- 按需综合评审、六帽评审与 Markdown 决策卡。
- 区分用户提供、AI 分析、待验证假设与真实外部核验；不代填用户最终决定。
- 仅5个指令/参考/元数据/许可文件，无运行脚本、服务、密钥或运行时依赖。

从插件版迁移不涉及数据转换。安装 ZIP 中完整目录到宿主技能位置，具体见[安装说明](install.md)。不使用 DSH“添加插件”流程。不会自动卸载旧插件、改写旧记录或读取旧数据库。

已完成与未完成的实测范围见[报告](report.md)。Codex 文件读取受本机权限问题限制，高级流程仍待复验；其他宿主仅有格式兼容预期。默认不联网核验，帽子不是六位独立专家，不承诺精确调用/费用/历史窗口。正式真人产品价值验证**未完成**，开发者模型测试不能证明优于普通 AI。
