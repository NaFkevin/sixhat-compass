# SixHat Compass · 六帽规划 — Preview.3

版本 **0.1.0-preview.3**，包名 **dsh-sixhat-compass**。这是面向 DSH 独立开发者的社区插件，使用宿主全局默认模型，在原生聊天中通过 @白帽、@黑帽、@绿帽等切换思考视角。

## 本版变化

- 固定产品名 SixHat Compass · 六帽规划，侧栏与设置仍使用简短中文“六帽规划”。
- 发送请求保存并受理后清空输入框，生成过程继续；下一条草稿不会被迟到结算清除。
- 回复支持复制、职责说明、上下文来源与调用记录；首token前停止不再把命令错误当作AI正文。
- 配置集中在 DSH 设置，记录页保留查找、恢复、决策卡编辑与导出。
- @评审 和 @六帽 是主动高级入口；单帽不自动生成卡片或启动其他角色。

## 安装与升级

实测 DSH CLI/Web **0.2.0-rc.2**、Node.js **24**、Windows、deepseek-official/deepseek-flash。下载本页 `.tgz`，先核对 `SHA256SUMS.txt`，再按安装说明操作。

旧 dsh-hexamind 或 dsh-liumao-planner 用户先备份并关闭目标宿主，移除实际已安装的旧包再装新包；修正 profile patch 中显式的旧 package name。内部配置ID、命令、API及存储目录保持兼容，不改写旧历史，不要同时启用旧包与新包。

## 已知边界

- 正式真人产品价值验证及真人对照尚未完成；非结构化试用反馈不能证明六帽优于普通AI。
- 只接受文本；模型工具列表为空，不执行命令、读文件或联网核验。模型建议不等于已核实事实。
- 上下文仅当前会话最近20条完整文本、最多24000字符；过长或更早内容不保证纳入。
- 宿主可能复用或隐藏纯命令会话，请用 @新讨论 创建独立讨论，从记录页返回旧讨论；卸载后视图可能隐藏，但日志与专属数据保留。
- 停止和崩溃恢复受最后成功落盘检查点限制，不承诺零费用或绝对无损。
- 原生Desktop、其他供应商、全部中文输入法与真实附件交叉验证尚未完成。

安装与详细证据见仓库文档。此次 Release 不包含密钥、私人会话、用户原始截图或本地运行库。
