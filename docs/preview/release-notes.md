## 安装与升级

下载本页 `.tgz` 并核对随附 `SHA256SUMS.txt`。Desktop 用户在“插件 → 添加插件”输入安装包完整路径。已有同名旧包的用户先停止任务并备份，再按宿主提示卸载旧包、安装新版；不要删除会话或 `storages/hexamind`。若旧插件已停用无法打开备份页，可在关闭目标宿主后另存该目录、会话目录和 profile patch。

支持的版本是精确列表；宿主以后升级到其他预览版本时，需重新核对和发布兼容声明。旧 Preview.3、Preview.4 不覆盖。CLI/Web 安装与完整步骤见 [install.md](install.md)。
