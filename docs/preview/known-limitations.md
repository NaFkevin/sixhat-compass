# 已知限制

已有开发者非结构化试用反馈，并据此修复输入框问题；尚无按协议完成的真人产品价值验证，无独立完成率、付费或回访结论。Phase D 的20个合成案例不能替代真人验证，也没有证明六帽普遍优于强单次。

仅实测 Windows / DSH Web 0.2.0-rc.2 / deepseek-official 的 deepseek-flash；原生Desktop、其他平台、其他模型和未来宿主版本未实测。

主流程仅文本、每条消息一顶帽子，附件不接受且保留草稿。历史上下文最多20条、24000字符完整消息，不保证覆盖更早或过长材料；本次问题不截断，来源与遗漏数量可展开检查。

模型为宿主全局默认模型，不一定等于原生聊天框临时选中的模型。帽子无命令、文件或联网工具，不默认核验事实。单帽正常1次，瞬态重试最多追加1次；@六帽通常6次，自动重试最多追加2次；追问和手动恢复另计。供应商内部重试、取消后计算和完整账单不可观测。

回复内容仍取决于模型，不代表真人反馈或独立专家意见。普通 Agent 不自动将 log-only 帽子命令注入其模型历史；连续 @帽子 会明确读取之前的帽子回复。普通聊天及它自己的权限、工具行为仍由 DSH 控制。

存储和备份含完整材料、请求、回复与来源，应去敏并妥善保管。崩溃只保证最后成功落盘检查点，不能保证未刷盘内容。未做掉电、共享盘或多用户数据库验证。

已结束的宿主命令记录保持原样。记录页恢复后的最新回复在插件记录中；卸载后通用命令卡展示原始命令结果。只有帽子的会话可能仍被宿主命名为“新会话”，可自行重命名。

DSH 的空白会话判定只在普通 turn/start 后改变，因此普通“新建会话”可能复用纯帽子会话，侧栏也可能不列出非当前纯命令会话。请使用不调用模型的 @新讨论 创建独立对话；从评审记录可返回旧讨论。卸载后宿主的纯命令聊天视图可能隐藏，重装插件后恢复；日志和专属存储不删除。

中文文本、候选键盘选择和未完成前缀回归检查通过；系统级真实中文输入法完整组合事件仍需人工交叉验证，自动化填入中文不等于全部输入法兼容测试。
